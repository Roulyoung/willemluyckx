# Client Review Message Template

Herbruikbare template voor toekomstige projecten.

## Invulvelden

- `PROJECT_NAME`
- `REVIEW_URL`
- `ADMIN_URL`
- `ROUND_LABEL`

## Template

> Hoi, voor **`PROJECT_NAME`** staat de review-flow klaar. Je kunt je feedback per pagina en per onderdeel geven via deze link:
>
> `REVIEW_URL`
>
> Wat je doet:
> - open de link
> - loop stap voor stap door de pagina's
> - geef per onderdeel aan wat goed is en wat nog aangepast moet worden
> - alles wordt automatisch opgeslagen, dus je kunt tussendoor stoppen en later verdergaan met dezelfde link
> - aan het einde zie je een samenvatting en kun je de versie goedkeuren
>
> Belangrijk:
> - het gaat om de bronversie van deze ronde (`ROUND_LABEL`)
> - je hoeft niets in Google Sheets te doen
> - als ik feedback heb verwerkt, stuur ik je dezelfde link opnieuw voor de volgende ronde

## Korte variant

> Review-link voor **`PROJECT_NAME`**: `REVIEW_URL`
>
> Geef per pagina en sectie feedback, alles wordt automatisch opgeslagen. Aan het einde kun je de versie goedkeuren.

## Admin reminder voor jezelf

- Admin: `ADMIN_URL`
- Na feedback verwerken: nieuwe ronde aanmaken
- Klant opnieuw laten checken
- Pas sluiten als de ronde echt akkoord is
