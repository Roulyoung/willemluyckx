# Session Commands

Gebruik dit als snel overzicht voor werken in deze projectmap.

## Session start

- `wt`
  Open Windows Terminal.

- `cx`
  Open een custom command window met de naam in de tab.

## Local development

- `npm run go`
  Start de local dev-server en opent direct Chrome op `http://localhost:5173`.

- `npm run dev`
  Start Vite met auto-open.

- `npm run build`
  Bouw de productieversie.

- `npm run lint`
  Draai ESLint.

## Notes

- Gebruik `npm run go` als standaard voor lokale ontwikkeling als je direct Chrome wilt.
- Zet dit document ook in de template-folder, zodat nieuwe projecten hetzelfde startgedrag krijgen.
