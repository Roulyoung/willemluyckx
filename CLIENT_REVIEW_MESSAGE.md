# Client Review Message

Gebruik dit wanneer je de klant de review-link stuurt.

## WhatsApp versie

> Hoi, ik heb de review-flow klaarstaan. Je kunt je feedback per pagina en per onderdeel geven via deze link:
>
> `https://topfitrunning.com/review/<token>`
>
> Wat je doet:
> - open de link
> - loop stap voor stap door de pagina's
> - geef per onderdeel aan wat goed is en wat nog aangepast moet worden
> - alles wordt automatisch opgeslagen, dus je kunt tussendoor stoppen en later verdergaan met dezelfde link
> - aan het einde zie je een samenvatting en kun je de versie goedkeuren
>
> Belangrijk:
> - het is bedoeld voor de review van de Nederlandse bronversie
> - je hoeft niets in Google Sheets te doen
> - als ik feedback heb verwerkt, stuur ik je dezelfde link opnieuw voor de volgende ronde

## Korte versie

> Review-link: `https://topfitrunning.com/review/<token>`
>
> Geef per pagina en sectie feedback, alles wordt automatisch opgeslagen. Aan het einde kun je de versie goedkeuren.

## Admin link

Gebruik dit zelf:

- Review admin: `https://topfitrunning.com/review-admin`

## Wat jij daarna doet

1. Open de review-admin.
2. Kopieer de review-link voor de klant.
3. Laat de klant de review-link invullen.
4. Lees de feedback terug via de summary of admin.
5. Verwerk de feedback.
6. Start daarna een nieuwe ronde als `V2`.
